- 提示词仓库保留目标项目现有后端同步机制，并从 `test` 只补入目标缺少的 Banana Prompt Quicker 与 Freestylefly GPT Image 2；目标已有且数量更完整的 YouMind Nano Banana Pro 不重复迁移。请在管理后台执行全部同步，确认新数据卷也能获取这两个分类。
- 导演台截图现在会同时创建画布图片节点和未生成的视频分镜节点，并自动将截图连接为视频首帧。请在视频节点补充提示词后手动点击生成，确认不会自动发起模型请求。
- 从 `test` 迁入的本地 Canvas Agent 节点协议已适配目标项目已有的 `panorama` 与 `director` 节点；连接完成后需验证读取、创建和更新这两类节点。
- 画布顶部新增“本地 Agent”入口，支持地址与令牌配置、协议校验、实时状态同步和写操作确认；Agent 请求中的自动生成动作会被强制跳过，只保留节点与连线编排。
- 画布库新增独立的 WebDAV 备份入口，支持同源代理连接测试、ZIP 上传和用户确认后的恢复导入。备份包含画布、素材索引、导演台工程、图片/视频生成记录及必要本地媒体；恢复会创建新画布和新记录，不会覆盖本地数据，也不会写入模型 Key、WebDAV 密码或 Agent 令牌。
- 本地 Canvas Agent 前端连接层与画布入口已接通：支持令牌鉴权、协议版本校验、画布状态防抖上报、SSE 工具请求和审批结果回传。Agent 可识别“导演台 → 截图图片”资源并创建视频分镜，但所有收费生成操作都会被跳过，必须由用户在网页中点击生成。
- 画布库新增插件管理入口。官方插件固定从 `guyu818/infinite-canvas` 的 `plugins-dist` 注册表安装，其他插件只能选择本地 `.js/.mjs` 文件；没有任意远程 URL 输入。Markdown、SVG、HTML、便利贴示例已纳入官方构建，全景图继续使用目标项目现有的内置实现；示例依赖会构建进插件包，运行时不再从第三方 CDN 执行脚本。
