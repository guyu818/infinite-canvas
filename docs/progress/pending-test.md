# 待测试

- 生图工作台标题旁新增醒目的“故事板”入口，内含“AI 生成故事板”和“拼接单张分镜”两个模式。AI 模式支持输入剧本、选择 2×2/2×3/3×3 宫格、单格画幅和视觉风格，可先填入主工作台审核或直接提交单张复合故事板生成；沿用主工作台已有参考图和模型配置。
- 故事板拼接支持批量上传单张分镜、从最近生成记录添加、上下调整镜头顺序、自动/指定宫格、16:9/9:16/1:1 单格比例、完整显示/填满裁切和镜头编号。拼接在浏览器本地完成，可预览、下载 PNG，或加入生图参考图继续创作，不会额外调用模型。
- 已有内容的视频节点悬浮工具栏新增“复刻TVC”。点击后会把该视频作为“参考视频1”打开画布 Agent；Agent 按平台、比例、时长、完整复刻/动作运镜/故事结构、音频字幕和真实商品信息一次性补齐制作条件。只有参考视频而没有用户商品图时不会继续生成；用户明确允许近似后才能使用非精确商品比例。
- 画布 Agent 新增参考视频复刻 / TVC 专用规则，完整复刻优先保持镜头顺序、动作节拍、场景顺序和时间比例，只替换用户批准的商品、人物与品牌资产；当前上下文没有逐帧或转写证据时不会伪称已完成逐镜分析。只有用户明确要求开始生成且模型支持视频参考时才进入现有视频任务链路。
- Codex 插件新增 `canvas_create_reference_video_tvc`：必须传入已有参考视频节点、至少一张用户商品图、商品真实信息和完整提示词；工具会创建 TVC 制作单、视频配置节点和真实素材连线，默认 `reference` 模式且不会自动调用收费模型。请分别验证正常流程、缺少商品图、无效素材节点和不支持视频参考模型的提示。
- LibTV 公开 Skill 只暴露“上传素材后把自然语言任务交给平台 Agent”的外部行为，没有公开其逐镜分析和工作流内部源码；本实现对齐该入口与 Agent 编排行为，但不会调用 LibTV 服务，也不会把普通文生视频冒充参考视频复刻。
- Codex 插件新增完整的画布插件节点控制：可列出已启用插件与动作、按插件默认值创建节点、用通用节点工具更新字段，并调用插件明确开放的声明式动作。Markdown、HTML、SVG、便利贴和全景示例均提供对应动作；所有写操作继续由网页确认，插件仍不能读取 API Key。
- 已有内容的视频节点悬浮工具栏新增“转白模”。点击后会在右侧创建并连线白模视频节点，继承源视频比例、尺寸和时长，预填纯白无纹理 3D 灰盒提示词；不会自动生成。配置的视频模型必须支持视频参考输入，用户确认参数后再点击生成。Codex 可通过 `canvas_create_white_model_video` 完成同样的流程编排。
- 项目新增 `.agents/plugins/marketplace.json`，Codex 插件版本升级为 0.3.0。安装后请新开 Codex 任务，确认可发现 Infinite Canvas 技能及新增 MCP 工具。

- 提示词仓库保留目标项目现有后端同步机制，并从 `test` 只补入目标缺少的 Banana Prompt Quicker 与 Freestylefly GPT Image 2；目标已有且数量更完整的 YouMind Nano Banana Pro 不重复迁移。请在管理后台执行全部同步，确认新数据卷也能获取这两个分类。
- 导演台截图现在会同时创建画布图片节点和未生成的视频分镜节点，并自动将截图连接为视频首帧。请在视频节点补充提示词后手动点击生成，确认不会自动发起模型请求。
- 从 `test` 迁入的本地 Canvas Agent 节点协议已适配目标项目已有的 `panorama` 与 `director` 节点；连接完成后需验证读取、创建和更新这两类节点。
- 画布顶部新增“本地 Agent”入口，支持地址与令牌配置、协议校验、实时状态同步和写操作确认；Agent 请求中的自动生成动作会被强制跳过，只保留节点与连线编排。
- 画布库新增独立的 WebDAV 备份入口，支持同源代理连接测试、ZIP 上传和用户确认后的恢复导入。备份包含画布、素材索引、导演台工程、图片/视频生成记录及必要本地媒体；恢复会创建新画布和新记录，不会覆盖本地数据，也不会写入模型 Key、WebDAV 密码或 Agent 令牌。
- 本地 Canvas Agent 前端连接层与画布入口已接通：支持令牌鉴权、协议版本校验、画布状态防抖上报、SSE 工具请求和审批结果回传。Agent 可识别“导演台 → 截图图片”资源并创建视频分镜，但所有收费生成操作都会被跳过，必须由用户在网页中点击生成。
- 画布库新增插件管理入口。官方插件固定从 `guyu818/infinite-canvas` 的 `plugins-dist` 注册表安装，其他插件只能选择本地 `.js/.mjs` 文件；没有任意远程 URL 输入。Markdown、SVG、HTML、便利贴示例已纳入官方构建，全景图继续使用目标项目现有的内置实现；示例依赖会构建进插件包，运行时不再从第三方 CDN 执行脚本。
- 插件节点已接入画布创建工具栏、侧栏、缩略图、悬浮工具按钮、自定义面板、主题上下文、上游资源输出和宿主 AI 调用接口。宿主只注入调用函数，不向插件上下文传递 API Key。
- 已新增 Agent 导演截图分镜、白模视频流程、令牌校验、禁止自动生成，以及插件发现/创建/动作调用、来源策略/资源输出、WebDAV 连接/空文件/鉴权/超时/清单校验/敏感字段过滤、恢复媒体引用改写和登录状态下本地模型路由测试。Web 单元测试 18 项全部通过；Canvas Agent 测试 133 项中 131 项通过、2 项按平台条件跳过、0 项失败；本轮未改后端，Go 回归沿用上一轮 Go 1.25 容器全部通过的结果。
- Web、Canvas Agent 与官方插件已实际构建通过；上一轮完整 Docker 镜像也已通过并运行。此次重建时 Docker Desktop 后端未能启动，Windows 服务需要更高权限，因此尚未把本轮镜像替换到 `localhost:3000`。`/api/local-ai/models` 的既有同源代理验证结论不变，真实模型与白模视频生成仍需使用用户自己的有效 Key 手动验收。
